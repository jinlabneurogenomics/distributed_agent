# BioKG Claims

- `claim_assignments.tsv`: 11,237 memberships connecting 11,199 Findings to
  5,107 Claims.
- `claim_relations.tsv`: 4,243 typed Claim-to-Claim relationships.
- `claim_assignments.summary.json`: exact layer counts.

The Claim layer is not an exhaustive Finding partition: 144 Findings are not
assigned to a Claim, and 38 Findings support more than one Claim.
