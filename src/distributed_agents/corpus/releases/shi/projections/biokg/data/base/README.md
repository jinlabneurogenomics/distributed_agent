# BioKG base graph

- `nodes.merged.csv`: 73,882 base nodes.
- `relationships.merged.csv`: 306,925 base relationships.
- `sourceguard_overlay_report.json`: node, relationship, publication, and CSV-hash checks.
- `reference_canonicalization_report.json`: Reference and `CITES` totals.
- `merge_report.json`: base-graph totals and hashes.

The base contains 11,343 Findings, 18,602 Evidence nodes, 15,797 Reference
nodes, and 8,999 LiteratureComparison nodes. The complete runtime graph is
stored under `../graph/`.
